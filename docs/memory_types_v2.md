# Seven lamps for memory

Different notes answer different questions. The M0–M6 vocabulary is a way to choose the right kind of record, not proof that seven databases or background engines are running.

- **[M0 / Episodic](../memory/m0_episodic/README.md): what happened?** A dated event with its source and observed result.
- **[M1 / Semantic](../memory/m1_semantic/README.md): what does this mean?** A definition or supported fact, preferably linked to its owning source.
- **[M2 / Procedural](../memory/m2_procedural/README.md): how do we do it?** A checked procedure with prerequisites and a recovery path.
- **[M3 / Intentional](../memory/m3_intentional/README.md): what are we trying to do?** A goal, owner, next action and completion condition.
- **[M4 / Affective](../memory/m4_affective/README.md): what mattered to someone?** Their expressed values and creative context, with attribution.
- **[M5 / Relational](../memory/m5_relational/README.md): who works with whom?** Roles and relationships, distinct from credentials and permissions.
- **[M6 / Predictive](../memory/m6_predictive/README.md): what might happen?** A hypothesis with evidence, a review date and a way to be wrong.

## Keep one useful home

The earlier migration copied several flat memory files into category folders without removing or updating the originals. That created conflicting working sets and broken relative links. Curation is replacing those duplicates with references to one current home.

Do not move the root symbol map merely because the old plan proposed it. Its consumers still expect it at the root, and [its schema mismatch remains open](SERIOUS-TODOS.md#shared-map-contract-mismatch).

The category should make a record easier to find. If it does not, a second copy and a new label are not an improvement.

## A small example

A failed build is an event: record the actual command and result. The lesson learned may become a procedure after a successful check. The unresolved fix belongs in the current task list. Those are three purposes, not three copies of the complete log.

The turtle asks: *“Will the next reader know which note to trust?”*
