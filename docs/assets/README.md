# Documentation assets

Store images here only when they help a reader understand a project or its visual language. A meme can be useful. Repeating it on every page is not a navigation system.

- Prefer SVG for diagrams and PNG or JPEG for appropriate raster images. Include meaningful alt text where the image is used.
- Keep filenames stable or repair the links when moving an asset.
- Review the actual image, embedded metadata, source and licensing before publishing. Check screenshots for information the owner did not intend to share.
- Keep private staging material outside this public working tree. Existing ignore patterns for `*.private.*` are convenience, not access control, and do not hide already tracked files.

The `memes/` illustrations are inherited artwork under review. Their existence does not mean every page needs a dungeon header or character panel.
