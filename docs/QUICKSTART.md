# Start with one useful question

SymbolOS connects a project's purpose, shared vocabulary and evidence to the next person or agent who picks it up. You do not need to install a model to read it.

## First visit

1. Read the [entrance](../README.md) for the purpose.
2. Choose one [reading path](reading_order.md). A newcomer should not have to read the entire archive.
3. Pick a project or a room in the [station map](station_map.md). Read its observation time and what its state actually means.
4. If you want to change something, read the [contribution guide](../CONTRIBUTING.md) and the [working boundaries](agent_boundaries.md).

You should leave with one clear next action or a question, not an assumed running service.

## Before running inherited tools

This repository contains early Windows/PowerShell launchers, an optional TUI and web experiments. They are being reviewed individually for relevance and current behavior. They are not a single installed operating system.

Do not run a folder-open task or an old launcher simply because a copied quickstart calls it recommended. Read its source, platform requirements, network access and expected changes first. A saved probe or a filename is not proof that a model endpoint is available.

If your goal is local inference, choose the actual model server you use and follow that project's current instructions. Its startup, model download, credentials and successful inference must be verified separately from SymbolOS's documentation.
