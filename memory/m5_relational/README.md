# M5: the party's relationships

Relational notes answer **who works with whom, in what role?** Distinguish a person, a narrative character, a harness and the model currently selected by that harness.

This folder contains older character sheets, not a running graph database or authoritative permissions registry. A class, score or claimed ability on a sheet is not proof of access, health or successful work.

The [character tree](../../docs/character_tree.md) is the newer relationship map. Its runtime statements still need their dates and evidence. Nobody's narrative role overrides another person's or agent's ownership.
