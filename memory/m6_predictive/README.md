# M6: the oracle's questions

Predictive notes ask **what might happen next?** Record a hypothesis, its evidence, an expiry or review date, and the observation that would prove it wrong.

This directory is a place for that form of note. Its name does not demonstrate a running Precog engine, shadow queue or experiment agent.

Rhy asks: *“What would change your mind?”* An answer is more useful than an invented confidence percentage.
