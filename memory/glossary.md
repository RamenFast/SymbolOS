# Continuity terms

- **Umbrella:** a reminder to respect the people, consent and ownership involved. The symbol does not make a file private.
- **Meeting place:** the shared vocabulary and current task context that let different sessions understand one another. `symbol_map.shared.json` is the inherited machine-readable vocabulary, not a permission source.
- **Repo-backed memory:** dated notes and decisions kept in Git. History helps establish provenance, but does not make old claims current or public files secret.

Use these words when they clarify the work. Explain the concrete behavior next to a metaphor instead of requiring a reader to decode it.
