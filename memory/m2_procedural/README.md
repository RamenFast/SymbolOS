# M2: the artisan's handbook

Procedural notes answer **how do we do this?** Good instructions state prerequisites, authorized scope, actions, expected results and a way to recover.

The contracts and boot cards here came from earlier workflows. Read them as historical designs until checked against the current machine and request. A copied procedure cannot grant permission to publish, delete or control another agent.

Keep current reusable procedures in their owning project's documentation or skill. Link there rather than promoting every inherited boot instruction into an active rule.
